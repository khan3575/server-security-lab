Server Security Lab

This page runs on a hardened Ubuntu 24.04 server behind Cloudflare.

How the request travels

  1. Browser opens lab.sakib-khan.com
  2. Cloudflare: DNS, proxy, SSL Full (strict), WAF, rate limit
  3. UFW firewall: only the needed ports are open
  4. Ubuntu 24.04: SSH keys only, fail2ban, automatic updates
  5. Nginx: HTTPS and security headers
  6. Docker container serving this page

This is a temporary test site. It has no login, forms or database.
